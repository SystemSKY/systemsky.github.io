3. Hosting über GitHub Pages

Beim Aufruf unserer Website wird eine Verbindung zu Servern von GitHub hergestellt. Dabei werden technische Daten (z. B. IP-Adresse, Browserinformationen, Zeitstempel) verarbeitet. GitHub speichert diese Daten zur Auslieferung und Optimierung des Angebots sowie aus Sicherheitsgründen.

Rechtsgrundlage für die Verarbeitung ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem sicheren und zuverlässigen Betrieb der Website).

GitHub kann Daten in die USA übermitteln. Die Datenverarbeitung erfolgt auf Basis von Standardvertragsklauseln gemäß Art. 46 DSGVO.

Sichere Verbindung (SSL/TLS):
Die Übertragung Ihrer Daten erfolgt über eine verschlüsselte Verbindung (HTTPS). Dadurch werden Ihre Daten während der Übertragung vor dem Zugriff Dritter geschützt.

Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub.
